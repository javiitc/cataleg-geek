# 📚 Catálogo de Videojuegos

Para nuestro pequeño catálogo de videojuegos, contamos con archivos **XML**, **HTML** y **CSS**.

- **XML**: Se utiliza para almacenar la información de cada videojuego, como el título, el año de lanzamiento, y otros datos relevantes.
- **HTML**: Se encarga de dar estructura a la web e indicar qué elementos deben mostrarse.
- **CSS**: Contiene los estilos necesarios para darle diseño y una apariencia atractiva al catálogo.
